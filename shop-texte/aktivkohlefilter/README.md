## Vorgaben

- Vorlage B (Granny's Weed / Kailar): Problem-Einstieg, Vorteilsliste mit fetten
  Labels, Tabelle „Technische Details", Praxistipps. Kein `<h1>` im Text — der
  Produktname ist auf der Seite bereits H1.
- Anrede „du" klein.
- Keine Shop-CTA in Beschreibung, Kurzbeschreibung oder Meta-Description.
- Keine Gesundheits-, Schadstoff-, Umwelt- oder Spitzenstellungsaussagen.
  Funktion beschreiben statt Wirkung versprechen.

- Farb-/Größenvarianten bleiben eigene Produkte (ausdrückliche Vorgabe) —
  deshalb bekommt jede Variante einen eigenen Farb- UND Größenteil, damit die
  Seiten nicht als Duplikate gegeneinander laufen.
